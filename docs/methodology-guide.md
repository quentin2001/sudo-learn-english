## 一、 理论基石：为什么“零查词泛读”能真正习得英语？

传统英语学习最大的误区是：**把语言当成一门“科学知识”去死记硬背（Learning），而不是当作一种“生物机能”去自然习得（Acquisition）。**

本体系基于二语习得（Second Language Acquisition, SLA）的四大支柱理论构建：

### 1. $i+1$ 可理解性输入假说 (Comprehensible Input Hypothesis)
* **$i$ (Current Level)**：你当前的语言能力。
* **$i+1$ (Sweet Spot)**：输入材料的难度仅比你当前水平高出一小步（**95%~98% 的单词都认识**）。此时你的大脑能借助上下文无缝理解整体意思，并自然推断出那 2%~5% 的未知部分。
* **$i+3$ (Frustration Zone / 崩溃区)**：如果一页书有十几个生词，大脑的“语法解码器”会过载，心流彻底中断，从“阅读”退化为痛苦的“中英翻译查词游戏”。

### 2. 情感过滤假说 (Affective Filter Hypothesis)
* 焦虑、痛苦、不自信会形成一道高高的心理防御墙（High Affective Filter），阻断大脑底层的“语言习得机制（LAD）”。
* **零查词、一口气读完一本原著带来的巨大成就感**，能彻底瓦解这道心理墙，让语言像母语一样被潜意识吸收。

### 3. 附带词汇习得 (Incidental Vocabulary Acquisition)
* 词汇不是靠背词汇书掌握的。一个生词在不同的真实语境中**自然相遇 7~12 次**，大脑就会自动掌握它的**语义边界、情感色彩与高频搭配（Collocations）**。

### 4. 窄读策略 (Narrow Reading)
* 连续阅读同一作者、同一系列或同一主题的书籍。由于同类书籍的核心词汇与句式重合度高达 **70%~80%**，第二本书会比第一本读得明显更快，形成“滚雪球”般的语感正反馈。

## 二、 原著阅读黄金守则 (The Golden Rules)

在阅读任何一本原版书时，请严格遵守以下法则：

```
                    ┌─────────────────────────┐
                    │      遇到生词怎么办？     │
                    └────────────┬────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       【不影响核心剧情/含义】               【影响核心情节且反复出现 5+ 次】
                 │                               │
                 ▼                               ▼
      【3秒法则：大胆盲猜 / 直接跳过】             【顺手快速查词并立刻回到阅读】
          （保护心流，保持语流向前）                   （绝不展开背诵，继续读）
```

1. **保护心流第一（Flow Over Perfection）**：阅读的主要目标是“享受故事、吸收思想”，绝不是“扫清所有生词”。
2. **3 秒法则（The 3-Second Rule）**：遇到生词，依靠上下文在 3 秒内猜一个大概意思（比如是褒义还是贬义、是动作还是物体），猜不出直接跳过，保持视线和思维向前奔流。
3. **拒绝即时查词打断**：切忌每遇到一个词就切出查词典，这会强行激活中文翻译通道，破坏英文思维回路。
4. **每天保持稳定节奏**：每天哪怕读 15~30 分钟，也远胜过周末突击 3 小时。

## 四、 读后三步内化法 (Post-Reading Internalization SOP)

阅读是输入，内化是将输入转化为**积极表达能力（Active Competence）**的催化剂。每读完一本书或关键章节，执行以下三步：

### Step 1: 提炼语块（Chunks & Collocations），而非孤立单词
* ❌ **错误做法**：抄录孤立生词 `tame` 并死记中文“驯服”。
* ✅ **正确做法**：提取生动语块 `to establish ties` / `to tame someone`（建立独特的羁绊）。

### Step 2: 生活场景微迁移 (Micro-Transfer)
* 大脑只对“与自己有关的事物”产生持久记忆。
* 把书里的好句，改写成一句描述你自己的真实生活、工作、家庭或代码的英文句子：
  * *原书例句*：`"You become responsible forever for what you have tamed."`
  * *生活微造句*：`"As a developer, I feel deeply responsible for the open-source code I have created."`

### Step 3: 苏格拉底式启发对话 (Socratic AI Dialogue)
* 借助 AI 进行 5~10 分钟的故事与观点探讨，在思想碰撞中激活词汇调用。

## 五、 与 AI 开展苏格拉底式启发对话的标准流程

每当你读完一本书（或读到有感触的章节），在对话中向 AI 发送指令（例如：`“我刚刚读完了《小王子》，我们来进行启发式内化探讨吧！”`），AI 将按照以下**三位一体节奏**与你互动：

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 【思想共鸣 (Intellectual Resonance)】                    │
│    • AI 针对你的观点进行平等的观点探讨与思想共鸣。             │
├─────────────────────────────────────────────────────────────┤
│ 2. 【表达升级小框 (Level-Up Collocations)】                  │
│    • 提取你刚才想表达的意思，展示原书中更地道、更高级的语块。   │
├─────────────────────────────────────────────────────────────┤
│ 3. 【启发式延伸追问 (Socratic Follow-Up)】                   │
│    • 抛出一个开放式问题，引导你自然运用刚才学到的新语块。       │
└─────────────────────────────────────────────────────────────┘
```

对话结束后，将精华内容沉淀到该书的专属档案（`books/NN-*.md`）中，完成该书的终身内化闭环！
